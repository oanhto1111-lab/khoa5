# Personal Portfolio Capstone

## Files
- `index.html` — semantic page structure and portfolio content
- `style.css` — visual design, responsive layouts, and dark-theme variables
- `script.js` — mobile navigation, theme switch, project filters, and contact form checks

## Preview
Open `index.html` in a modern browser. Keep all three files in the same folder.

## Personalize before submitting
Replace “Alex Morgan”, the short biography, project descriptions, and `hello@example.com` with your own information. Add your real project links if available.

## Evidence to capture
1. W3C HTML Validator: submit `index.html` at https://validator.w3.org/ and capture the results. Fix any reported errors before submission.
2. Responsive layout: capture the page at a desktop width and at a mobile width (for example, using browser developer tools).
3. CSS: include `style.css` in your submission or show it in a code editor.
4. Four extra features: demonstrate the theme switch, project filters, mobile menu, and contact form validation.

The contact form is a front-end demonstration only. It does not transmit or store messages.
